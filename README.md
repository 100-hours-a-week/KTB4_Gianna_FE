# Raffiné - Frontend

## 프로젝트 소개
Raffiné 서비스의 프론트엔드 레포지토리입니다. 스스로 무엇을 좋아하는지 모르는 사람들을 위해 사용자가 자신의 취향과 경험을 게시글로 기록하고, 다른 사용자와 댓글 및 토론을 통해 생각을 나누는 웹 서비스 입니다.

### 서비스 사용
- [Raffiné](http://54.180.97.37/)
### 기능 및 목적

- 사용자 회원가입, 로그인, 계정 관리 화면 제공
- 게시글 목록 조회 및 상세조회
- 게시글 작성, 수정, 삭제 기능 제공
- 게시글 이미지 업로드 입력 지원
- 댓글 작성 및 댓글 목록 조회 화면 제공
- 토론 페이지를 통한 대화형 기록 흐름 제공
- 백엔드 API와 연동되는 프론트엔드 사용자 경험 구현

### 기술 스택

| 구분 | 기술 | 사용 목적 |
| --- | --- | --- |
| Frontend Library | React 19 | 사용자 화면 구성 및 컴포넌트 기반 UI 구현 |
| Routing | React Router DOM | 페이지 이동 및 라우팅 처리 |
| Build Tool | Vite | 개발 서버 실행 및 프로덕션 빌드 |
| Language | JavaScript | 프론트엔드 로직 작성 |
| Styling | CSS | 페이지별 UI 스타일링 |
| Package Manager | npm | 의존성 설치 및 스크립트 실행 |
| API Communication | Fetch API | 백엔드 API 요청 처리 |
| Dev Proxy | Vite Proxy | 로컬 개발 환경에서 백엔드 서버와 API 연동 |

## 설치 방법

### 요구 사항

- Node.js
- npm

### 설치

```bash
npm install
```

### 개발 서버 실행

```bash
npm run start
```

개발 서버 실행 후 브라우저에서 안내되는 로컬 주소(localhost)로 접속합니다.

### 빌드

```bash
npm run build
```

빌드 결과물은 `dist` 디렉터리에 생성됩니다.

## 문제 해결 방법

### 화면에서 API 요청이 실패하는 경우

백엔드 서버가 실행 중인지 확인합니다. 만약 서버가 실행 중인데도 오류가 발생했다면 아래 도움 창구로 오류 메세지와 화면을 캡쳐하여 알려주시길 바랍니다. 

*(tip! 브라우저 개발자 도구의 Network 탭에서 실패한 요청의 상태 코드와 응답 메시지를 확인하면 원인을 좁히기 쉽습니다.)*

### 변경한 화면이 반영되지 않는 경우

만약 로그인한 지 시간이 지나 메인 페이지에 게시글이 뜨지 않거나, 오류가 발생한다면 재로그인, 개발 서버를 재시작, 브라우저 캐시를 새로고침하는 방법을 통해 해결할 수 있습니다.
